# Gamepad Controls

The game fully supports both modern and retro-style controller input!

## Two Controller Modes

### 1. Full Gamepad Mode (Default)
Modern controllers with dual analog sticks

### 2. Limited Gamepad Mode (SNES-Style)
Retro controllers with D-Pad + 8 buttons only

## Menu Navigation (D-Pad Only)
- **D-Pad Up/Down**: Navigate menu options
- **A Button (Cross/X)**: Select/Confirm
- **B Button (Circle/O)**: Back/Cancel

## Full Gamepad Mode

Perfect for Xbox, PlayStation, or Switch Pro controllers.

### In-Game Controls:
- **Left Stick / D-Pad**: Move character
  - Up/Down: Forward/Backward
  - Left/Right: Strafe Left/Right
- **Right Stick**: Camera look
  - Up/Down: Look up/down
  - Left/Right: Look left/right
- **A Button (Cross/X)**: Jump
- **B Button (Circle/O)**: Sprint
- **Start/Menu Button**: Pause (toggle mouse capture)

### Keyboard Controls (Default):
- **WASD**: Movement
- **Mouse**: Camera look
- **Space**: Jump
- **Shift**: Sprint
- **Escape**: Toggle mouse capture

## Custom Control Mapping

Visit the **CONTROLS** menu from the main menu to:
- Remap any action to your preferred keys or gamepad buttons
- Support for keyboard, gamepad buttons, and analog sticks
- Individual camera axis remapping
- Reset to defaults at any time

All custom mappings are automatically saved and loaded between sessions!

## Limited Gamepad Mode (SNES-Style)

Perfect for retro gaming with classic controller layouts! **See LIMITED_GAMEPAD_MODE.md for full details.**

### Quick Summary:

**What you get:**
- D-Pad + 4 Face Buttons (A, B, X, Y)
- 2 Shoulder Buttons (L, R)
- Start & Select buttons
- No analog sticks needed!

**Default Layout:**
- D-Pad: Movement
- A: Jump
- B: Sprint
- L/R or X/Y: Camera rotation
- Start: Menu

**3 Camera Modes:**
1. **Tap L/R or X/Y** - Snap rotate 45° per tap (Default)
2. **Hold X + D-Pad** - Manual camera control
3. **Auto-Follow** - Camera follows movement direction

**How to Enable:**
Go to CONTROLS → Enable "Limited Gamepad Mode" → Choose camera mode

**Compatible with:**
- SNES controllers
- 8BitDo controllers (SN30, SF30, etc.)
- Genesis/Mega Drive controllers
- Any simple gamepad without analog sticks

## Controller Compatibility

The game uses Godot's standard controller mapping which supports:
- Xbox controllers
- PlayStation controllers
- Nintendo Switch Pro controllers
- Most generic USB/Bluetooth controllers

Enjoy exploring the infinite terrain with your preferred control method!
